# 全球主流广告平台 AI 产品与合规变更追踪

**品类**：`ads-platform` · **类型**：`public-feed`（产出公开，可订阅）
**隐私等级**：公开 —— 所有信源均为各平台官方一手公开信息，不含私有数据

---

## 解决什么问题

广告行业的 AI 变化太快，跟不上。行业媒体滞后且不全，官方 changelog 和政策页又分散在十几个地方、更新无声无息。

这条 loop 每天把这些一手信源扫一遍，**过滤掉营销通稿，只留能改变今天投放动作的变更**。

**判断标准就一条**：看完能不能改今天的投放动作。不能的不留。

## 为谁跑

投放操盘手、代理商、增长负责人。

对投放人来说信息差就是预算差；对产品人来说，这是平台商业化形态更迭的一线样本。

## 产出长什么样

每条变更固定给四件事——**变更内容 / 生效日期 / 影响范围 / 官方原文链接**，缺一不算合格。

当日无实质变更时，明确产出「今日无影响投放决策的变更」，**不硬凑条目**。

## ⚠️ 已知脆弱点

`dependencies` 里标了 `fragility: high` 的一项：**各平台官方页面结构**。页面一改版抓取就失效，而且失效时往往是**静默的**——产出会变空或变少，不会报错。

对应的失败信号写在 `LOOP.md` 的验收标准里：**连续 3 天产出为空 → 大概率信源改版，需人工核信源清单。**
