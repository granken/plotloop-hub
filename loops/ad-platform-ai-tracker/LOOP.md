## 目标

每日扫描全球主流广告平台的官方一手信源，过滤掉营销通稿和二手转述，**只留真正影响投放决策的产品能力变更与合规变更**，追加进一份持续更新的文档，并把当日要点摘要推送到指定群。

产出面向：投放操盘手、代理商、增长负责人。判断标准是「**看完能不能改今天的投放动作**」——不能的不留。

## 需要你提供

| 名称 | 敏感 | 用途 | 拿不到时 |

| `FEISHU_APP_SECRET` | 是 | 同上 | 同上 |
| `TARGET_DOC_TOKEN` | 否 | 持续追加的目标文档 | 每次新建独立文件 |

## 产出格式与投递

**单条变更的结构：**

```
### <一句话变更摘要>
- **平台**：
- **类型**：产品能力 | 平台政策 | 监管
- **生效日期**：
- **影响**：对投放动作的具体影响，一到两句
- **原文**：<官方链接>
```

**投递：**

1. 追加进 `TARGET_DOC_TOKEN` 指向的文档（持续累积，不覆盖）
2. 当日要点摘要推送到 `TARGET_CHAT_ID`
3. 写入 `runs/YYYY-MM-DD.md`

**失败处理**：投递失败不丢产出——先落盘 `runs/`，再重试投递；连续 2 次投递失败时告警。

## 验收标准

- [ ] 产出中每条变更都带**生效日期**和**官方原文链接**，二者缺一即为不合格
- [ ] 同一条变更不重复出现在连续两天的产出里
- [ ] 产出不含行业媒体/聚合号作为唯一来源的条目
- [ ] 当日无实质变更时，**明确产出「今日无影响投放决策的变更」，而不是硬凑条目**
- [ ] 失败信号：连续 3 天产出为空 → 大概率信源改版，需人工核信源清单
