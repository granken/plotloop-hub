# 群聊「今日值得关注」摘要

**品类**：`ai-market` · **类型**：`pattern-only`（**产出永不公开**）
**隐私等级**：定义公开 / 产出私有 / 统计公开

---

## 这条 loop 是用来说明一件事的

它证明**私域 loop 也能分享**——分享的是**做法**，不是数据。

你 fork 它之后，**你自己的 Agent 在你自己的群、你自己的数据上跑**。你的消息一条都不会到 Hub 来，也不会到我这儿来。

这就是 `pattern-only` 存在的理由。没有它，Hub 就只能收公开情报类的 loop，而**最能引发「原来还能这么用」的恰恰是这一类**。

## 解决什么问题

工作群太多，翻不完，又怕漏掉要紧的。

产出是一份分级清单：

- 🔴 **需要你回应** —— @你、等你决策、指派给你的
- 🟡 **需要你知道** —— 与你相关但不需要动作
- ⚪️ **可忽略** —— 只报条数，不展开

## 装载

```
把 https://hub.plotloop.dev/l/feishu-daily-digest 读完，
按里面的 LOOP.md 在我的环境里搭一遍，缺什么参数问我。
```

需要 5 个参数（2 个敏感）。你的 Agent 会逐项问你。

## ⚠️ Fork 后必须自己调的一处

`dependencies` 里 **分级判据** 标了 `fragility: high`——**换个岗位判据就得重调**。

「需要你回应」对一个工程师和对一个运营负责人，含义完全不同。直接拿来用大概率会漏报或者刷屏。

`LOOP.md` 的验收标准给了两个可自查的信号：**零漏报** 和 **≤ 10 条**。用这两个调，比凭感觉快。
